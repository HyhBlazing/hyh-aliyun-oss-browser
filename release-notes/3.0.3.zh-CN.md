# 3.0.3

设置与关于页增强，并清理仓库中的历史无用代码。

> 与阿里云无官方隶属或背书关系。

## 主要变更

1. **开机自动启动**：设置 → 应用 中可开启/关闭（系统登录时自动启动）。
2. **关闭策略提示**：关闭主窗口说明改为感叹号悬停提示，界面更简洁。
3. **关于页**：展示本地版本与 GitHub 线上版本，并可打开 Releases 检查更新。
4. 设置弹窗宽度自适应（最小约 500px）；更新应用图标资源。
5. 移除 Electron 2.x `legacy/` 树及过时脚本/文档/模板资源，仓库仅保留 3.x。

## 下载说明

- Windows：`.msi` / NSIS `.exe`（主要测试平台）
- Linux：`.deb` / `.rpm` / `.AppImage`（以 Release 附件为准）
- macOS：仅 Apple Silicon（`aarch64`）；当前不提供 Intel Mac 包
