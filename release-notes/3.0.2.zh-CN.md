正式发布跨平台安装包（Windows / Linux / macOS Apple Silicon）。

> 与阿里云无官方隶属或背书关系。

## 主要变更

1. 安装包内置独立 sidecar，**无需再安装 Node.js**。
2. macOS 提供 **Apple Silicon（M 芯片，aarch64）** 构建。
3. 桌面端启动时自动拉起传输服务；开发模式优先使用源码 sidecar。
4. 修复 macOS CI 目标配置，确保 M 芯片产物可正常产出。

## 下载说明

- Windows：`.msi` / NSIS `.exe`
- Linux：见 CI / Release 附件（deb/AppImage 等，以实际产物为准）
- macOS：Apple Silicon（M1/M2/M3/M4）；当前不提供 Intel Mac 包
