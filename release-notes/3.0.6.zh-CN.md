## 主要变更

1. **修复 CI / 打包类型错误**：解决 `vue-tsc` 类型检查失败导致无法产出安装包的问题。
2. **Release 自动挂载安装包**：标签构建成功后，Windows / Linux / macOS 安装包会自动上传到对应 Release。
3. **包含 3.0.5 修复**：拖拽或选择文件夹上传时保留原始目录结构。

## 下载说明

- Windows：`.msi` / NSIS `.exe`（主要测试平台）
- Linux：`.deb` / `.rpm` / `.AppImage`（以 Release 附件为准）
- macOS：仅 Apple Silicon（`aarch64`）；当前不提供 Intel Mac 包

请等待 Actions 构建完成后再下载「资源」中的安装包；若仅看到 Source code，说明安装包仍在生成中。
