## 主要变更

1. **拖出下载**：拖到资源管理器文件夹或桌面松手后，识别目标路径并加入下载队列，右下角显示每个文件进度；选中时不再预先下载。
2. **系统剪贴板**：支持将对象复制为系统文件剪贴板，便于在桌面/资源管理器粘贴。
3. **框选与列表交互**：修复预览遮罩导致无法框选等问题，选中与拖出手势更稳定。
4. **传输与默认并发**：下载任务默认最大并发调整为 50；传输队列与进度展示更可靠。
5. **设置与界面**：去掉多余缩放提示；全局搜索去掉横向滚动条；检查更新对 GitHub 限流等状态提示更清晰。
6. **其它**：favicon、新建文件夹体验、多实例相关能力等桌面端改进。

## 下载说明

- Windows：`.msi` / NSIS `.exe`（主要测试平台）
- Linux：`.deb` / `.rpm` / `.AppImage`（以 Release 附件为准）
- macOS：仅 Apple Silicon（`aarch64`）；当前不提供 Intel Mac 包

请等待 Actions 构建完成后再下载「资源」中的安装包；若仅看到 Source code，说明安装包仍在生成中。
