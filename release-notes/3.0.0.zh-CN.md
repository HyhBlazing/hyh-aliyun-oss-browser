## 架构

1. 新架构：Tauri 桌面壳 + Vue3/Vite UI + Node Fastify sidecar（ali-oss）。
2. Electron 2.x 代码迁入 `legacy/`，历史安装包见 Releases · v2.0.0。

## 主要能力

1. AccessKey / Token 登录，多 Key 历史切换，备注与保持登录。
2. Bucket / 对象浏览，收藏夹，快捷键导航。
3. 上传 / 下载 / 移动复制队列；传输面板可拖拽调整高度。
4. 获取地址 / 批量获取地址（公开直链与私有签名）。
5. 图片、视频、音频预览（音频含频谱可视化）。
6. 设置：默认下载目录（每次询问 / 固定目录）、网络代理、任务并发等。
7. 窗口最小尺寸与位置记忆；自定义应用图标与产品名。

## 运行要求（Windows）

- 安装包已内置 transfer-sidecar 资源；本机仍需可用的 **Node.js 20+**（用于拉起 sidecar）。
- 安装后首次启动若提示找不到 sidecar，请确认安装完整且 Node 已加入 PATH。
