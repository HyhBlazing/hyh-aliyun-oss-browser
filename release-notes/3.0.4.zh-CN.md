## 主要变更

1. **全局搜索（Beta）**：支持索引搜索 / 即时搜索；可取消进行中的搜索；结果支持批量下载、删除、取址、完整性校验等。
2. **本地元数据索引**：建立 / 增量更新 / 清除；显示索引对象数、本地占用与对象合计大小；进度条按扫描进度更新。
3. **自动索引**：设置中可开启「每天定时」与「登录后若过期则更新」；开始 / 完成 / 失败时给出界面提示。
4. **界面缩放**：默认 110%，范围 90%～125%，本机记忆。
5. **传输与完整性**：传输后自动校验、历史保留策略、代理等设置项完善；拖拽上传/下载体验优化。

## 下载说明

- Windows：`.msi` / NSIS `.exe`（主要测试平台）
- Linux：`.deb` / `.rpm` / `.AppImage`（以 Release 附件为准）
- macOS：仅 Apple Silicon（`aarch64`）；当前不提供 Intel Mac 包

安装包由打 `v3.*` 标签后的 CI 构建；若 Release 附件稍后补齐，请稍候刷新 Releases 页面。
